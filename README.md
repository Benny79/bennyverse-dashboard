# BennyVerse status board

One-page dashboard for the GitHub issues and releases of `Benny79/bennyverse`. Not part of the game.

Open `index.html` in a browser (double-click it). Paste a GitHub fine-grained token for `Benny79/bennyverse`
with: Issues (read/write), Contents (read), Actions (read), Metadata (read). The token is kept in this
browser's localStorage only; "Forget token" clears it. Never commit a token.

No build step, no dependencies, no backend.
